# Gamyasarthi - Bhanumurthy Punnamaraju

Official professional website for **Bhanumurthy Punnamaraju** — Senior Career Mentor, Consultant & Educator.

## Technology Stack
- **Framework**: Next.js 16 (App Router)
- **CMS**: Sanity (Headless CMS via Content Lake)
- **Styling**: Tailwind CSS
- **Language**: TypeScript

## Key Sections & Flow
1. **Home / Hero**: Overview of 20+ years expertise, stats, and primary calls to action.
2. **About Founder**: Professional biography, philosophy, credentials, and achievements.
3. **Services**: Specialized career counseling, admission guidance, professional pivots, and webinars.
4. **Mentoria Packages**: Replicated from Mentoria's standard & premium frameworks (Grades 8-9, Grades 10-12, College Graduates, Working Professionals) plus custom add-on packages.
5. **Testimonials**: Verified reviews from students, parents, and professionals.
6. **Contact Us**: Comprehensive enquiry form and direct contact channels.

## Sanity CMS
All content, prices, features, images, and text can be dynamically managed and updated via Sanity Studio (Project ID: `dzec4bbu`).
